# Lab8_CRUD

Учебное WinForms-приложение на C# для управления списком студентов в базе данных MS SQL Server с поддержкой всех CRUD-операций.

## Функционал
- Просмотр, добавление, редактирование и удаление записей о студентах
- Проверка на дубликаты по ФИО перед добавлением
- Экспорт таблицы в файл CSV
- Отображение общего количества студентов в статус-баре

## Запуск проекта
1. Склонируйте репозиторий: `git clone https://github.com`
2. Откройте файл решения `.sln` в **Visual Studio**.
3. Укажите свою строку подключения `connectionString` в `Form1.cs`.
4. Нажмите **F5** для запуска.
